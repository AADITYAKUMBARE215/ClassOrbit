# ClassOrbit

> Complete Coaching Management & Learning Platform

ClassOrbit is a scalable web platform designed for offline coaching institutes to manage students, teachers, batches, classes, tests, study material, attendance, assignments, communication and academic analytics.

The platform is being designed to support 10,000+ students while maintaining a secure, scalable and maintainable architecture.
